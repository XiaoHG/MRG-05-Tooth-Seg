# 摘要

标注质量是决定目标检测模型性能的关键因素。公开口腔影像数据集多依赖自动预标注，存在漏检、误检与边界偏移等系统性标注缺陷，若直接用于训练，会以错误监督信号误导模型学习，并干扰不同检测算法的公平比较。针对该问题，本文建立了一套面向单类别牙齿检测的人工复核标注规范与闭环质量控制流程，对 OMNI_COCO 数据集进行系统性标注清洗，并构造复核前后严格配对的两个数据版本。在统一的数据划分、输入尺寸、训练轮数、随机种子与验证流程下，本文分别训练 YOLO11n、YOLO11s、YOLOv8m、YOLO26m 与 RT-DETR-L 五种 CNN 与 Transformer 检测模型，以 Precision、Recall、mAP@0.5 与 mAP@0.5:0.95 评价检测性能。实验结果表明，人工复核后的标注在全部五种模型上均带来稳定提升，其中强调边界定位质量的 mAP@0.5:0.95 增益最为一致。本研究证实标注质量改进能够产生可测量的跨架构检测收益，为口腔影像检测的数据构建与模型评估提供了可复现的参考基准。

**关键词：** 牙齿检测；标注质量；人工复核；目标检测；OMNI_COCO；医学影像
