## 版本分析

### 1. 任务定义和明确边界

本版的输入是一张口内照片，主要面向直接咬合后的正面照片，也允许采集角度存在一定变化。模型的输出仅针对图中实际可见且可判读的牙齿：每颗牙的边界框、FDI 编号、检测置信度和可见牙总数。调用方只需要提交图像，由同一个多类别检测模型直接完成可见牙的定位和 FDI 预测。

这里的“一张图片”指一次预测只输入一张图，而不是只有一张图用于训练。若训练集真的只有一张图片，模型无法学习牙齿外观、牙位位置、个体差异或成像变化，任务不可实现；该图片只能用于验证预测接口是否能读取和保存结果。要训练可泛化模型，仍需收集和标注大量同类口内照片。

单张二维图像只能给可见牙编号，不能可靠判断画面外、被嘴唇或颊部遮挡、重叠或模糊的牙是否存在。因此，未出现在输出中的 FDI 只能表示“不可见或未检出”，绝不能自动判定为缺失牙。对局部照片、严重偏转照片和质量不足照片，系统应允许输出低置信度或“不判定”，而不是强制产生错误 FDI。

### 2. 模型定位

本项目将论文中的 YOLO11 牙齿定位与 FDI 枚举思想用于单张正面口内图，但不复刻其完整的两阶段分割流程。本版只训练一个直接输出 FDI 类别的 YOLO11 多类别检测模型；Light HQ-SAM 像素级分割留待具有逐牙 mask 标注后再实现。

该方案以方向一致、构图相近的正面咬合照片为主要适用范围。若将大幅偏转、咬合面、自拍镜像和局部裁剪等差异很大的图片混入同一模型，牙齿外观和相对位置会显著变化，必须针对这些输入另行收集标注数据并分别评估，不能默认保持正面图的效果。

### 3. 当前数据集的实际缺口

当前 `dataset/project-1` 有 22 张图像，其中训练集 18 张、验证集 4 张；`classes.txt` 只有 `tooth`，每个标签行均为类别 `0` 加检测框坐标。它可用于验证“是否检测到牙齿”的单类流程，但不能用于学习 FDI，也不足以作为有效的训练、验证或测试集。

为实现本版目标，当前数据至少缺少以下信息：

- 每颗可见牙对应的 FDI 标注。仅有框而无 FDI 时，模型无法区分 11、12、21、22 等牙位；事后按横向坐标排序也不可靠，因为存在缺失牙、局部图、拍摄偏转和牙列异常。
- 图像级元数据：匿名受试者 ID、采集日期或批次、是否为标准正面咬合照、是否镜像、图像质量和拍摄设备。受试者 ID 用于防止训练集和测试集泄漏，不能作为模型输入。
- 标注规则：适用人群是恒牙、乳牙还是混合牙列；缺失牙、萌出不全、种植牙、修复体、正畸附件、遮挡牙和无法判读牙如何处理。
- 独立且按受试者划分的验证集和测试集。随机按图片划分会使同一患者的相似图片进入不同集合，得到虚高的结果。
- 足够的数据量和类别覆盖。22 张图片无法覆盖每个可见 FDI、不同牙列、光照、嘴唇遮挡、设备和拍摄距离。

### 4. 可行性、不可实现边界和风险

在“成人恒牙为主、照片方向一致、以正面咬合照为主、每颗可见牙有专家 FDI 标签”的前提下，使用 YOLO11 直接检测 FDI 是可行的。模型可同时学习牙齿位置、形态和上下颌关系，并将 FDI 作为检测类别输出。

以下情况不能仅靠模型或后处理可靠解决，必须通过采集规范、标注或产品提示处理：

- 镜像照片：镜像会交换患者左右侧，进而使如 11 与 21 的语义互换。若不实现镜像检测和标签映射，就必须要求输入图像未镜像，并在数据导入时人工检查；训练中不能使用普通的水平翻转增强。
- 只拍到少量牙齿：没有完整牙弓、上下颌关系或足够邻牙时，某些牙位在图像信息上本来就难以区分。应输出较低置信度或“不判定”，不能承诺所有局部图都可唯一编号。
- 不可见牙：单图无法区分“患者缺失该牙”和“该牙不在画面内或被遮挡”。本版不应输出全口缺牙诊断。
- 非目标人群和异常牙列：乳牙、混合牙列、严重拥挤、修复体、种植体和正畸附件若未被训练集覆盖，会造成漏检或 FDI 混淆。应先限制适用范围，或为其收集独立样本并单独评估。
- 数据偏差：若数据来自单一设备、医生或拍摄环境，跨设备和跨机构性能可能下降。必须保留不同来源的独立测试集，不能只在同一批数据上报告结果。

### 5. 数据收集计划

第一阶段应先固定一份采集协议，而不是先大量收集难以使用的图片。建议将目标定为“非镜像、横屏或方向统一、成人恒牙为主、张口咬合后的正面口内照片”，并明确最小清晰度、曝光、牙列覆盖范围和排除条件。每个受试者可贡献一张或少量符合该协议的照片；预测时仍然只输入一张。

数据量应按受试者和牙位实例共同规划：

- 概念验证集：先收集约 100 名受试者的合规图像，完成全部可见牙的 FDI 标注，用于验证标注规则、训练命令和输出格式，不用于宣称临床性能。
- 初始可用基线：每个常见、可见 FDI 类别在训练集中至少约 200 个已复核实例，同时保留足够的缺失牙、遮挡和不同拍摄条件样本。由于单张正面图通常不会显示全部 32 颗牙，实际需要数百名受试者。
- 稳定评估集：独立保留至少 20% 的受试者作为测试集；如条件允许，再保留来自不同设备或采集者的外部测试集。任何测试集都不得参与训练、早停或阈值选择。

收集时为每个图像建立清单，至少含 `image_id`、匿名 `subject_id`、`orientation_confirmed`、`mirror_confirmed`、`quality_status`、`source_batch` 和 `include_reason`。原始图像不可覆盖，去标识化和访问权限应符合伦理审批、知情同意和数据安全要求。

### 6. FDI 标注计划

使用 Label Studio 或 CVAT 对每颗可见、可判读牙齿画紧致矩形框，并赋予 FDI 类别。成人恒牙的类别可采用 `11` 至 `18`、`21` 至 `28`、`31` 至 `38`、`41` 至 `48` 共 32 类；每个 YOLO 类别 ID 与 FDI 的映射必须存放在单一版本化配置中，例如 `0: 11`、`1: 12`，并同时生成 `classes.txt` 和 `data.yaml`。

标注前必须形成书面指南，至少规定：

- FDI 的左右方向以患者解剖方向为准，并在采集协议中固定图像方向；导入图像时确认非镜像。
- 只标注可见且能够由专业人员确认的牙；被遮挡、模糊或无法确认者不强行赋予 FDI，并在图像级或对象级元数据中记录原因。
- 缺失牙不创建框；种植牙、冠修复牙和正畸附件是否沿用原 FDI，要由临床专家统一规定；乳牙和混合牙列在初版中建议排除。
- 每张图完成后执行第二人复核；对 FDI 分歧、边界框分歧和不可判读案例建立仲裁记录。至少抽取一部分样本双人独立标注，以量化一致性。

标注导出后应自动检查图像与标签是否一一对应、坐标是否在范围内、类别是否在 FDI 映射内、同一图像是否有重复 FDI、同一受试者是否跨训练/验证/测试集合，以及每个 FDI 的实例数。当前只允许类别 `0` 的数据校验逻辑必须改为读取该映射后才能用于新数据。

### 7. 模型和训练计划

模型首选为单一 YOLO11 多类别检测器：输入整张口内图像，类别为 FDI 编号，输出框、类别和置信度。`YOLO11n` 适合先建立速度快的基线；若细粒度 FDI 混淆仍高，再在相同数据和评估条件下比较 `YOLO11s` 或更大模型。模型变更必须通过独立测试集指标决定，而不是只看训练损失。

训练流程如下：

1. 根据 `subject_id` 划分训练、验证、测试集，建议先采用约 70%/10%/20%，并保存固定的划分清单。
2. 将图像缩放到固定输入尺寸，例如 1024；保留纵横比并使用 letterbox，避免拉伸牙形。
3. 使用预训练 YOLO11 权重进行迁移学习，先以 `YOLO11n`、可配置 epoch、batch size、学习率和早停参数训练基线。
4. 仅使用不改变 FDI 语义的增强，例如亮度、对比度、色彩、轻微模糊、小角度旋转和小尺度变化。关闭水平翻转；若未来要接收镜像图，必须另行实现镜像检测或同步交换 FDI 标签后才可使用。
5. 每轮在验证集上保存最优权重，并记录每个 FDI 的样本数、precision、recall、AP、混淆矩阵及典型错误图。类别稀少时优先补充数据，不应只靠过采样掩盖问题。
6. 固定模型和阈值后，仅在从未参与开发的受试者级测试集上报告最终结果；训练权重、配置、数据版本和结果统一保存到 `output/` 下可追溯目录。

建议将“单类牙齿检测”保留为基线 A，将“直接 FDI 多类别检测”作为基线 B。只有当 B 的检测与编号指标均达到预设要求时，才能作为后续分割和氟斑牙分级的定位前置模块。

### 8. 预测、输出和评估计划

预测命令只接收一张图片和训练好的权重。模型经过置信度阈值和 NMS 后，对每个有效框输出 FDI、联合检测/分类置信度、像素坐标和裁剪图；整图叠加图应标注 FDI 和置信度。结果 JSON 至少包含图像标识、模型版本、阈值、可见牙总数、检测列表以及被拒绝或无法判定的原因。

“置信度”应明确为 YOLO 对该框及其 FDI 类别的预测分数，不等同于临床诊断把握。建议设置三个状态：高于阈值的 `accepted`、介于两个阈值之间的 `review_required`、低于最低阈值或图像质量不合格的 `rejected`。人工复核后的修正结果应回流到后续数据版本。

评估至少包括检测 mAP、每个 FDI 的 precision/recall/AP、已正确匹配检测框上的 FDI 分类准确率、同图重复 FDI 比例、可见牙数量的 MAE，以及按图像质量和拍摄偏转程度分组的指标。不能用“预测到的牙数”替代 FDI 准确率，也不能把未标注的不可见牙计为模型漏检。

### 9. 增量实施流程和 v4 验收

1. 固化任务范围、采集协议、FDI 映射、标注指南和输出 JSON 草案，并由口腔专业人员确认。
2. 收集并双人复核概念验证数据，完成受试者级划分；先不改动现有单类数据和已有推理功能。
3. 新增 FDI 数据集读取、类别映射和校验能力，并为合法 FDI、重复 FDI、镜像拒绝、跨受试者泄漏和空标签写自动化测试。
4. 训练并评估 YOLO11n 多类别基线，检查预测可视化和每牙位错误；根据错误补充数据或修订标注指南。
5. 在不改变既有单类命令行为的前提下，新增 FDI 训练与单图预测入口，保存带 FDI 的 JSON、叠加图和单牙裁剪结果。
6. 在冻结测试集完成评估和误差复盘，再决定是否扩展模型规模、接入分割阶段或收集特殊人群数据；每次迭代同步更新 README 的数据结构、训练命令、预测命令和输出字段说明。

v4 的最低验收标准是：对满足采集协议的单张正面口内图，系统能识别可见牙，输出可追溯的 FDI、边界框、置信度和可见牙总数，并在受试者级独立测试集按牙位报告检测和编号指标。v4 不包含 Light HQ-SAM 的像素级分割、不可见牙推断或氟斑牙分级；这些任务分别需要逐牙 mask 标注和临床分级标注，不能由当前检测框与 FDI 结果直接替代。
