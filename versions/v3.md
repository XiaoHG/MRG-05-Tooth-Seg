# 版本安排

- 基于版本 `v2` 的单文件推理能力，扩展为批量推理
- 新需求：传入一个图片目录，自动处理目录下所有符合格式的图像
- 输出方式保持不变，仍按原图建立结果子目录，保存单牙级推理结果
- 版本迭代完成后补充说明和命令到README.md文件

# 分析报告

## 目标

v3 的目标是把单张图片推理升级为批量推理，适合一次性处理整个数据集、文件夹或实验样本集。这样可以减少重复命令执行的成本，也更适合后续做大规模验证和结果整理。

## 功能定义

- 输入一个图片路径目录
- 自动筛选目录中的有效图像文件
- 对每张图执行同样的推理流程
- 结果仍按 `predict/<image-name>/` 结构保存
- 保留单牙级输出、整图可视化和检测元数据

## 设计分析

v3 是对 v2 的工程化增强，不改变模型主体，只扩展推理入口的使用方式。它的核心价值在于把“单次实验”变成“批量实验”，更适合做数据集级的推理验证、统计分析和结果归档。

这种设计的优点是实现简单、风险低、和现有输出结构兼容。由于每张图仍然独立落盘，因此不会引入复杂的结果合并逻辑，也便于后续人工抽检和二次处理。

## 使用场景

- 批量跑完整个测试集
- 对新收集的口腔图像文件夹做快速推理
- 输出单牙级结果供后续分析或标注复核

## 结论

v3 是一个合理的批量化版本，它把 v2 的单图推理能力扩展为目录级推理流程，能够更高效地支撑实验验证和数据整理工作。
