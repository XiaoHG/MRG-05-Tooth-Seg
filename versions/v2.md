# 版本安排

- 基于版本 `v1` 的推理结果，新增一个后处理模块
- 模块目标：将预测得到的整张牙齿分割结果，按单颗牙齿拆分并保存
- 保存位置：`predict/` 目录下按原图建立子目录
- 文件命名：以原图文件名为基础，按牙齿序号追加后缀
- 保存格式：统一使用 `PNG`
- 输出内容：单颗牙齿的分割原图、mask 或可视化结果，并记录置信度信息

# 分析报告

## 目标

v2 的目标是在 v1 已经跑通的牙齿检测基础上，进一步把推理结果细化为“单牙级输出”，方便后续做牙齿编号核查、分牙统计、局部可视化和下游分类任务。

## 功能扩展

- 推理结束后，对每张图中的每颗牙齿分别保存结果
- 每颗牙齿独立生成输出文件，避免多牙结果混在同一张图里
- 输出目录按原图自动分层，便于检索和管理
- 为每颗牙齿附加置信度，方便筛选低质量结果

## 设计分析

v2 本质上是对 v1 的后处理增强，而不是重新训练模型。它保留了检测模型的主体能力，只把输出从“整图结果”转换为“单牙结果”。这种方式的优点是实现成本低、兼容性强、便于调试，也能直接服务于后续的牙齿级别分析任务。

如果后续要进一步支持更精细的研究，v2 还能继续扩展为：

- 单牙裁剪图
- 单牙 mask
- 单牙置信度筛选
- 单牙编号校验
- 单牙特征提取

## 结论

v2 是一个合理的中间版本，它把检测结果从图像级提升到牙齿级，为后续分割分析、分级任务和临床可视化打下基础。
