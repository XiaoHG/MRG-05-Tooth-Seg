
1. 牙齿检测：必要加入transformer架构进来降低错检的风险，因为牙齿的区域应该只是在口腔的固定区域，而不应该检测到设备嘴唇等部分，transformer应该能够有效的识别到这个关系从而有效降低错检的风险；使得模型能够关注到牙齿应该处于的位置；
2. 牙齿检测：目前模型的认知中，会极大的将白色高光等特征识别成牙齿，从而操作误检的结果；需要降低这种误检率
3. 牙齿检测：目前模型的认知中，同样的误检是将牙齿中的金属固定器，也检测成牙齿，这应该是OMNI_COCO的标签所带来的训练结果，因为在OMNI_COCO中很多标签都将金属部分标记为牙齿；这个方面是否要做修正；
4. 牙齿​​检测：但是很奇怪的是对于一些很明显是牙齿的区域却是没有检测出来，像门牙，有少数是直接没有检测出来的，
5. 牙齿检测：牙齿之间的排布应该是相邻有序的，而不是距离比较离谱的，所有需要让模型能够学习的这个特征可以减少误检率 --> 创新点
