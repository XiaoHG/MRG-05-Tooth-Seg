## 分析报告

### 1. 当前数据集状态

`dataset/project-1` 目前已经包含一批通过 Label Studio 标注的数据，可用于工程搭建的初始验证。

- 图像数量：22
- 标签数量：22
- 图像与标签文件名一一对应
- 类别文件：`classes.txt` 中只有一个类别 `tooth`
- 元数据：`notes.json` 中记录了类别信息，结构正常

### 2. 标注格式判断

当前 `labels/*.txt` 为 YOLO 检测格式：

```text
class x_center y_center width height
```

检查结果表明：

- 所有标签都是 5 列
- 类别 id 全部为 `0`
- 坐标均在 `0~1` 范围内
- 每张图包含 6 到 23 个目标，平均约 15.23 个

因此，这批数据**符合 YOLO 检测任务的要求**，可以直接用于单类牙齿检测训练。

### 3. 图片尺寸情况

当前图片尺寸不统一，包含多种分辨率。

结论：

- 对 YOLO 检测任务来说，图片尺寸不一致是可以接受的
- 训练时会自动进行 resize / letterbox
- 不建议手动拉伸变形

### 4. 任务适配性

当前数据集更适合做：

- 牙齿检测
- 牙齿框定位
- 最小闭环的目标检测验证

当前数据集**还不适合直接做分割**，因为现有标签是框标注，不是 mask 或 polygon 掩膜。

### 5. 最小闭环建议

建议先完成如下闭环：

1. 数据检查
2. 训练集 / 验证集划分
3. 使用 `YOLO11` 训练单类 `tooth` 检测模型
4. 对测试图做推理
5. 导出检测框、可视化图和结果文件

### 6. 后续扩展方向

如果后续要进入牙齿分割，需要把标注格式升级为：

- `Polygon`
- `Brush`
- 或其他可导出为 segmentation 的格式

如果后续要做氟斑牙分级，还需要额外构建：

- 分级标准
- 分级标签
- 分类或多任务模型
