## 1. 研究问题与论文定位

### 1.1 主问题

> **在患者/来源隔离、标签语义清晰、同计算与同下游预算的条件下，口内域继续预训练何时优于直接使用 DINOv3 base？**

这是一个可证伪问题，不预设正向或负向结果。

### 1.2 论文定位

- **当前主路径 B：受控评估**；
- 路径 A 只在 I1 出现明确牙科特定机制、并通过强对照后升级；
- 路径 C（临床筛查）暂不进入排期；
- 完整牙齿分割/FDI/临床诊断只作为远期动机，不写进当前标题或贡献声明。

### 1.3 工作标题（暂定，不锁定）

> *When Does Intraoral Domain Pretraining Help? A Controlled Evaluation of DINOv3 Adaptation for Dental Images*

标题、摘要、结果在干净数据重评后再定。

## 2. G0-A：数据与医学任务审计

**目标**：把“数据/标签是什么”写成不可变协议，避免在语义不清的数据上做确认性比较。

### 2.1 逐图审计表

每张图至少记录：

- 原路径、SHA256、近重复簇 ID；
- 来源（AlphaDent / COde / OMNI / Oral-Diseases / dental_fluorosis）；
- 原始标签、当前目录标签、是否跨类重复；
- 患者 ID、场景/拍摄 ID、牙位/ROI（若有）；
- 纳排理由、许可/使用限制、split。

交付：`data_protocol_v1` + 冲突裁决记录。

### 2.2 必须裁决的三件事

1. **六类口腔疾病的任务语义**
   - 720 张 → 643 唯一哈希、40 重复组、22 跨类组；
   - 选择：
     - A. 互斥单标签（排除共病/冲突组）；
     - B. 多标签（Calculus + Gingivitis 等）；
     - C. 仅作图像目录识别（不称疾病诊断）。
   - 三者对应不同模型头、损失、指标和论文主张，不能混用。
2. **氟斑牙分级标准**
   - `dental_fluorosis` 200 张（199 唯一）目前只有 4 级目录；
   - 需确认 Dean 指数、TF 指数还是项目自定义四级；
   - 标注者、复核人数、一致性、患者 ID、整图/单牙/患者级单位。
3. **ROI/牙位**
   - 当前两个分类集没有现成牙齿 ROI 真值；
   - OMNI 有牙齿框，但不能自动赋氟斑牙等级或六病标签；
   - ROI 只能用人工框或固定检测规则生成，并区分“预测 ROI”与“真值 ROI”。

### 2.3 通过的证据门槛

- 六病是互斥、多标签还是目录识别，必须写清；
- 跨类冲突需人工/来源证据，不能自动改标签；
- 若缺患者 ID，明确结论只到图像/簇级；
- 若标签无法裁决，暂停六病确认性实验。

## 3. G0-B：切分与统计协议

### 3.1 分组优先级

1. 患者 ID；
2. 场景/拍摄/原图；
3. 近重复簇（感知哈希/embedding）；
4. 来源。

同一组只能出现在一个 fold；验证集与最终测试集按同一层级互斥。

### 3.2 指标

| 任务 | 主指标 | 辅助 |
| --- | --- | --- |
| 氟斑牙 4 级（有序） | QWK | MAE、相邻级准确率、macro-F1、混淆矩阵 |
| 口腔疾病 6 类（互斥） | macro-F1 | balanced accuracy、类级灵敏度/特异度 |
| 口腔疾病（多标签） | per-class AP / AUROC | 类级校准、共病分析 |

- 不再把六类疾病的 QWK 作主指标；
- 不把 5 折 × 5 seed 的 25 折当独立观测；
- 配对差值用 cluster bootstrap 或独立分组折；优先报告效应量与 95% CI；
- 多重比较需预声明或校正。

### 3.3 开发/确认性分离

- 开发集：选模型、调参、误差分析；
- 确认性测试：只做最后一次估计；
- 当前 200/720 已被多次用于观察，事后划 20% 仍是**回顾性切分**，不能称“从未接触的测试”；
- 若无法获得新增独立数据/来源，论文定位为“图像级、来源受限的探索性估计”。

## 4. G1-A：现有权重的低成本干净重评

**对象**：base、5k、10k、15k、16k。

**做法**：

1. 用 G0 的 manifest 重新核对 `eval-*` 的 `features.npz`、逐折 CSV、路径/标签/哈希/配置；
2. 在 224 CLS 上重算分组评估；
3. 报告：
   - 逐图/逐簇预测；
   - 配对差值与簇级 95% CI；
   - 类别/来源分层；
   - 主指标（氟斑牙 QWK+MAE；疾病 macro-F1）。
4. 修正原报告符号：原“base − checkpoint”实际是“checkpoint − base”；
5. 不保留未经核实的 p 值；如报 p，先明确检验单位与多重比较。

**通过门槛**：

- 结果可追溯到固定 manifest 与代码版本；
- 若疾病标签尚未裁决，只出描述性审计，不出性能排名。

---

## 5. G1-B：读出与尺度探索

**对象**：base、15k/16k（必要时 5k）。

**比较**：

- 224 / 384 / 512 输入；
- CLS vs 整图 patch mean；
- 按原图短边分层（<256、256–384、384–768、>768）；
- ROI pooling：仅在有人工 ROI 或固定检测规则 + 误差审计后进行；
- patch 对应/局部检索：需真实局部标签或可审计对应关系。

**结论边界**：

- patch mean 仍是全局池化，不是 dense/分割证据；
- 若只用预测框，报告框误差及其对结论的影响；
- 明确 CLS 的下降是否延伸到局部特征。

---

## 6. G1-C：下游适配比较

**对象**：base vs 最佳现有 Stage 1 权重。

**比较**：

- frozen；
- 监督 LoRA / 部分解冻；
- 200 张任务谨慎全量微调；
- 相同输入、头、搜索预算、训练种子。

**结论边界**：

- 若 adapted 只在某一划分/调参预算下占优，不能归因于 SSL；
- 监督 LoRA 检验“权重可适配性”，不等于 SSL 阶段 LoRA；
- 三类结果不互相替代。

## 7. R：条件性新 SSL 训练

**暂缓**，等 G0/G1 的误差分析、确认性测试来源与训练成本清楚后决定。

### 7.1 R0：同预算当前 recipe 基线

- 同一清洁 SSL manifest；
- 同一 base 初始化；
- 固定 40 epoch/步数（约 5,360 步，134 step/epoch）；
- 记录配置 diff、卡时、显存、原型利用率、checkpoint。

### 7.2 R1/R2：单变量

- R1：只改一个数据/增强因素，或只改 LR；
- R2：仅在预算允许时加；
- R0/R1/R2 共用数据、步数、评估和搜索预算；
- 不用旧 120 epoch 结果当 40 epoch 的严格同预算对照；
- 入围方案多种子验证。

### 7.3 R-advanced：Gram / 512 / 蒸馏

只在 G1/R 显示密集表征/锚定问题，且完成显存冒烟后启动。

- Gram：
  - `gram.use_loss: true`、固定 teacher checkpoint、`gram_teacher_crops_size`、`img_level` 与 crop 对齐；
  - 当前 `img_level: false`、B=320、224 时 Gram 矩阵约 62,720²，fp32 约 15.7 GB，25GB 下高风险；
  - 先试 `img_level: true`/分块/小 batch；
- 固定 base 蒸馏：先与无蒸馏同预算对照；
- 512 Stage 2：先与 224 续训同预算对照；
- 没有通过冒烟/对照，不启动。

## 8. 论文方案与创新点定稿

### 8.1 论文最低贡献（路径 B）

1. 可复查的患者/近重复/来源协议；
2. 标签冲突的有理处理（互斥/多标签/目录识别）；
3. 同预算 base vs SSL vs 多读出 vs 监督适配；
4. 能回答“何时有益/无益”的误差与分层分析；
5. 可复现的代码、split/哈希、统计协议。

### 8.2 创新点定稿

| 编号 | 定位 | 论文角色 |
| --- | --- | --- |
| I2 数据协议 | 当前最可交付 | 主贡献之一（需新证据） |
| I5 ROI/patch 评估 | 当前最可交付 | 主贡献之一（需新证据） |
| I1 base-anchored adaptation | 候选 | 条件升级；需牙科特定机制 + 强对照 |
| I3 softmax+center/K/N | 弱 | 实现细节/消融 |
| I4 单牙 token/牙间 Transformer | 潜在高 | 论文 B，独立规划 |

### 8.3 方法稿升级门槛

I1 必须在固定 base 蒸馏、Gram-only、来源平衡、下游 LoRA 等强对照之外，展示可重复的额外收益；单次“蒸馏 + Gram + 平衡采样”组合改进不足以证明方法创新。

### 8.4 现在可以写的部分

- 研究问题与可证伪假设；
- 数据来源、许可、审计流程；
- 任务标签定义（待核实处明确标注）；
- 统计计划、模型与预算；
- 与 DINOv3、DinoDental、DOVE 等的差异表；
- 计划表/图：数据流转、同预算对比、frozen/LoRA、来源/分辨率分层、消融、资源消耗。

结果、摘要、标题在数据清理后重写，不用当前受污染 probe 数字预先定标题。

## 10. 风险与停止规则

| 风险 | 处理 |
| --- | --- |
| 六病标签无法裁决 | 暂停六病确认性实验；只做描述性审计 |
| 无患者/近重复独立测试 | 只作图像/簇级探索；不称患者泛化 |
| G1 局部/下游适配均无改善 | 优先整理受控评估，不默认追加新训练 |
| Gram/512 显存不可行 | 不以缩小样本/改变 batch 冒充同预算对照 |
| 当前 200/720 已被反复使用 | 承认选择偏差；新增独立数据优先 |
| 预算压力 | 先 G0/G1，R0+1 个单因素，不铺满 R1–R5 |
