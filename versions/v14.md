## 3. 本版本任务与验收标准

### 任务一：多源公开牙科数据集清单

- 内容：盘点候选公开数据集（AlphaDent、COde-Dataset、OMNI_COCO、Oral-Diseases、OralSDv1、DentalAI、Mendeley、BMC Oral Health 等），记录来源/许可/模态/任务/标注/规模，并与本地 `dataset/` 实际数据合并出清单。
- 验收：
  - 每个数据集有来源、URL、许可、模态、任务、标注、规模、本地状态（downloaded/partial/not_downloaded/reference_only）。
  - 本地已下载数据的图像/标签/分片数量由脚本自动重算，不手写。
  - 输出缺口分析（现状 vs 约 20 万目标）。

### 任务二：噪声图剔除规则

- 内容：定义并实现「黑屏/过曝/模糊/无牙」噪声图剔除规则，两层：
  - 静态层（无模型）：不可读文件、欠曝（近黑）、过曝（白爆）、模糊（Laplacian 方差低）。
  - 模型层（yolo11n 或更优）：检测不到牙齿，或仅低置信度检出 1–2 颗即剔除。
- 验收：
  - 规则可配置（阈值经 CLI 传入），默认 dry-run 不移动文件。
  - `--apply` 只隔离（移入 quarantine）不删除；拒绝运行于 `dataset/raw/`。
  - 有逐图 CSV 报告 + 规则说明 + 单元测试。

## 4. 本版本执行结果（收口记录）

- **任务一（数据集清单）**：新增 `tools/build_dataset_inventory.py`，内置 11 条数据集 registry（OMNI_COCO / AlphaDent / omni_coco-alphadent 合并集 / COde / Oral-Diseases / OralSDv1 / DentalAI / Mendeley / BMC Oral Health / TLNM / 自建氟斑牙），本地扫描自动重算数量。产物 `output/a1-data-integration/dataset_inventory.md` + `.json`。
  - 本地磁盘图像 14191 张（含 OMNI_COCO before/after 同图两版、合并集重复）、标签 13954 个；去重后唯一自然口内图像约 5759 张（合并集 5618 + 氟斑牙 141）。
  - 缺口：约 19.4 万张；清单指出「约 20 万」为愿景值，公开可下载量级约 7 万（COde 5 万 + Oral-Diseases 1.27 万 + BMC 6313 + AlphaDent 1320 + TLNM 1272），论文中需如实说明整合规模。
- **任务二（噪声剔除规则）**：新增 `tools/filter_noise_images.py`（静态层：亮度/高光占比/Laplacian 清晰度，纯 PIL；模型层：yolo11n 检出数 + 最大置信度）。默认 dry-run；`--apply` 隔离不删除；拒绝 `dataset/raw/`。dry-run 冒烟：`dataset/positive`（141 张）命中 blurred 2 张（1.4%）。
  - 起始阈值：`--min-brightness 12`、`--max-highlight-ratio 0.85`、`--min-sharpness 30`、`--min-teeth 2`、`--min-confidence 0.5`；需在人工标注样本上校准后再用于全量数据。
- 单元测试：`tests/test_dataset_inventory.py` + `tests/test_noise_filter.py`，共 10 条，全部通过。
- 结论：v14 达成「数据集清单 + 噪声图剔除规则」验收线，可进入 v15（A2 域内预训练）。
