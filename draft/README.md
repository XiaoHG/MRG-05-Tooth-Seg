### 研究问题提出

##### 研究背景分析
- 随着视觉基础模型与自监督预训练技术的快速迭代，医学图像智能分析已从传统监督学习范式迈入域内基础模型预训练、迁移微调的全新发展阶段，基于通用视觉基座开展医学领域自适应预训练，是当前牙科人工智能研究的主流热点。现阶段牙齿智能检测、病灶识别、牙体分割等下游任务大多依赖少量标注样本开展监督训练，存在人工标注依赖性强、牙科影像标注门槛高、细粒度病灶特征提取困难、跨设备跨数据集域偏移明显、泛化性能受限等痛点。传统 CNN 与早期视觉 Transformer 模型受训练范式与数据规模约束，很难充分挖掘口腔影像中低对比度的牙体解剖与病变特征，模型在临床场景的落地效果常常达不到预期。
以 DINOv3 为代表的新一代自监督视觉基础模型，依托无需标注、大规模表征学习、强迁移泛化的优势，在医学影像感知任务中表现出巨大潜力。但原生 DINOv3 在自然图像上完成预训练，学到的特征偏向自然物体纹理，和口腔影像的灰度分布、牙体解剖形态、牙科病灶的细微纹理存在显著域鸿沟，直接迁移至牙齿检测任务时，牙科专属表征能力不足，下游微调增益有限。目前牙科领域虽然陆续发布了 AlphaDent、CODe-Dataset、OMNI_COCO、OralSDv1、Oral-Diseases 等多类公开影像数据集，但这些数据集大多独立分散存放、单库样本体量有限、模态与采集标准不统一，缺少面向自监督预训练的整合资源，很少有研究将多源公开牙科数据集汇总融合用于域内预训练，制约了牙齿专用视觉骨干模型的构建。
针对上述研究空白，本研究整合 AlphaDent、CODe-Dataset、DentalAI、OMNI_COCO、Oral-Diseases、OralSDv1 等多个公开口腔牙齿数据集，构建总量约 20 万张的大规模多源口腔牙齿影像集合，以 DINOv3 自监督框架为基座开展牙齿领域自适应预训练，搭建面向牙齿检测任务的专用预训练模型。依托多源异质公开数据学习牙齿解剖与病变的通用视觉表征，弥补通用基础模型在牙科场景的域适配缺陷，降低下游龋病、氟斑牙、根尖病变等检测、分割任务对稀缺标注数据的依赖，提升模型跨数据集、跨设备的泛化能力，为口腔影像智能诊断任务提供高质量的域内预训练骨干权重，进一步推动感知类 AI 在口腔临床诊疗中的应用。

# 创新点分析

## 判断依据与边界

当前工作已经具备一项可被实验支持的数据中心贡献：在相同数据划分、训练协议和验证流程下，人工复核后的 OMNI_COCO 标注使 YOLO11n、YOLO11s、RT-DETR-L、YOLOv8m 和 YOLO26m 的检测指标整体改善，其中严格定位指标 mAP@0.5:0.95 的改善尤为稳定。该结论仅适用于当前单类别牙齿边界框检测，尚不能延伸为分割、牙位识别或临床诊断能力。

近期牙齿检测研究主要集中于检测器替换、多类别对象和特定放射影像任务；已有工作开始将先验知识用于牙齿及修复体检测结果的校正，也开始考察图像质量、正畸器械和 Transformer 注意力对检测性能的影响。结合本项目中白色高光、器械/口唇区域、正畸金属部件和漏检门牙等错误现象，候选创新应以“可定义、可实现、可消融验证”为准，而不能仅以使用 Transformer、构建向量库或移动端部署作为创新。

## 候选创新点

### 1. 标注质量感知的牙齿检测基准与闭环复核方法（优先作为当前论文主创新）

**核心思想。** 建立“错误类型定义—人工复核—成对数据训练—跨架构验证—困难样本回流”的闭环。除常规漏标、重复标注和框偏移外，单列金属固定器是否属于牙齿、牙冠高光、口唇/设备反光、遮挡牙和边缘牙等标注规则；对各类错误记录来源、复核结论和修改类型。将 before/after 作为严格配对数据，而不是将复核数据仅作为一个新数据集报告单次最优结果。

**创新性与可行性。** 该方向的贡献在于把标注质量变成可操作、可量化的变量，并证明其收益是否跨 CNN 和 Transformer 检测器成立；现有五组配对实验已提供直接基础。其学术价值高于“比较若干现成模型”，但需要补足标注变更统计、至少多个随机种子、固定独立测试集和误差分层结果，才能将“指标提升”归因于复核策略。

**关键验证。** 报告各错误类型的修订数量；在固定测试集上比较 before/after；按正常牙、高光、金属部件、遮挡和边缘牙分层统计 Precision、Recall、mAP@0.5:0.95；以多模型和多随机种子报告均值及离散度。该候选项可立即写入现有 OMNI_COCO 论文主线。

### 2. 牙弓结构约束的候选框重评分与缺失提示（优先级高）

**核心思想。** 在检测器输出后引入轻量牙弓结构模块，而不是强行假设每张图都具有完整固定牙列。模块先估计口腔有效区域和牙弓主轴，再将候选框投影到弧长坐标，依据相邻框间距、重叠程度、尺寸突变和偏离牙弓的程度生成结构一致性得分。该得分用于重排低置信候选、抑制孤立误检，并将异常大间隔标记为“待复核缺失候选”，不直接虚构检测框。

**针对的问题。** 可直接对应高光或设备造成的孤立假阳性、牙齿间距不合理，以及少数门牙漏检。Transformer 的全局关系可作为基线比较对象，但“使用 Transformer”本身不足以证明获得了牙弓先验；显式、可解释的结构约束才是可检验的技术点。

**关键验证。** 与原始检测器、仅口腔区域过滤、仅 NMS 阈值调整进行消融；分别统计假阳性、漏检、平均每图错误数和严格定位指标；按完整牙列、缺牙、遮挡和局部视野分组。必须保留缺牙、乳牙、口张开不全和裁切图像，避免结构规则造成新的漏检。

### 3. 面向高光与金属部件的语义困难负样本学习和标注一致性校正（优先级高）

**核心思想。** 建立非牙齿困难样本库，重点收集牙冠高光、正畸托槽/弓丝、金属修复体、吸唾器、口唇及设备反光。先通过临床或标注规范明确“牙齿实例”的边界：金属部件是单独排除、与牙齿框共存，还是按可见牙冠范围标注；再将规则一致地应用于训练和评价。训练阶段以难例挖掘、类别无关的背景抑制损失或受控的数据增强提高模型对这些干扰的区分能力。

**创新性与风险。** 将“白色即牙齿”的纹理偏差转化为可测量的困难负样本问题，且与项目已观察到的错误直接对应。该方向的前提是修正标签语义冲突；若同类金属部件在不同图像中被不一致地标为牙齿，任何损失函数都无法给出可靠结论。不要把未审核的模型伪标签当作困难负样本真值。

**关键验证。** 建立人工确认的困难测试子集，报告该子集的每图假阳性数、Precision 和误检类型占比；比较基础训练、仅标注校正、仅困难样本训练及二者结合；检查正常牙齿 Recall 是否因更强的背景抑制而下降。

### 4. 基于视觉表征检索的标注审计与主动复核（优先级中）

**核心思想。** 将“超大牙齿向量数据库”收敛为服务于数据质量的检索系统：以图像块、候选框和预测错误为单位提取视觉表征，检索与已确认的高光、金属部件、漏标牙或框偏移样本相似的实例；优先提交模型高不确定性、模型间分歧大或与近邻标签不一致的样本供人工复核。系统输出的是相似病例和审核队列，不替代人工标注或临床判断。

**创新性与可行性。** 相比单纯建立向量库，该方案有明确的输入、复核对象和效率指标，并可与候选项 1 的闭环连接。可先采用通用自监督视觉特征和近邻检索实现，不必先训练大型专用表征模型。

**关键验证。** 在相同人工审核预算下，对比随机抽样、置信度排序和检索/分歧排序，评估单位审核时间发现的标签错误数、被纠正错误类型数，以及经复核后下游检测性能变化。该项适合作为数据治理方法或后续论文，而非当前检测对比论文唯一主线。

### 5. 资源受限场景的检测—审计双轨部署（优先级低，作为转化方向）

**核心思想。** 端侧仅运行轻量牙齿候选检测和质量提示，云端或离线端完成结构约束、相似病例检索和人工审核队列生成；按照置信度和网络状态决定是否上传。移动端应用与云服务是系统价值，而非算法创新，除非同时证明在目标设备上的时延、内存、能耗、隐私处理和检测性能。

**关键验证。** 在指定手机或边缘设备上报告端到端时延、峰值内存、模型大小、离线可用性和与服务器模型的精度差；明确其仅提供图像质量与候选检测辅助，不输出临床诊断。

## 模型结构候选创新点

以下三项属于模型层创新，需要在现有 YOLO 或 RT-DETR 基线外新增网络模块、训练配置和权重管理；仅以某个现成模型替换基线，或仅在推理阶段调节阈值，均不构成这些方法的实现。

### 6. 牙弓先验引导的双分支检测网络（优先级最高）

**模型设计。** 以主检测分支提取局部纹理和边界特征；并行设置牙弓先验分支，从多尺度特征预测连续的“牙齿可出现性”密度图和牙弓方向场。该辅助监督可由现有边界框自动生成：以每颗牙齿框中心为核生成密度图，以相邻牙中心的局部方向生成方向场，无需新增像素级分割标注。通过跨注意力或特征门控，将先验分支输出注入检测颈部和分类头，使处在合理牙弓区域且与邻近牙一致的候选得到支持，而远离牙弓的高光、口唇和设备反光被降权。

**模型创新点。** 将牙列的空间可出现性作为可学习的软先验，与外观检测联合优化；它既不同于仅使用 Transformer 的全局注意力，也不同于仅在输出端用规则过滤。软先验不要求完整牙列，因此对缺牙、截断图像和张口不足应保留低置信响应，而非直接删除候选。

**训练目标与消融。** 总损失可写为 `L = L_det + lambda_d L_density + lambda_o L_orientation`；依次比较原始检测器、仅密度监督、密度加方向监督、加入跨注意力/门控后的完整模型。除总 mAP 外，必须报告牙弓外假阳性、高光/器械假阳性、门牙漏检和缺牙样本 Recall。建议以 RT-DETR-L 作为首个实现基线，因其查询特征适合融合全局先验；轻量 YOLO 版本用于验证通用性与端侧代价。

### 7. 牙列关系图驱动的检测查询精炼网络（优先级高）

**模型设计。** 以检测器的候选框或 Transformer object queries 作为图节点，节点特征由外观嵌入、置信度、中心坐标、尺度和牙弓坐标组成；按预测的弧长邻近关系构造稀疏边。图注意力模块在候选之间传递“相邻、重叠、间隙异常和尺度连续性”信息，输出更新后的分类置信度与边界框偏移。训练时使用匹配到真实牙齿的节点构造正关系，未匹配候选与明显非牙区域构造负关系，并加入对相邻间距和排序一致性的软约束。

**模型创新点。** 该方法把“牙齿相邻有序”的知识嵌入可学习的候选关系图，使模型能够利用牙齿之间的关系纠正局部视觉歧义。与固定规则后处理相比，关系权重、可接受间距和尺度变化由数据学习；与一般 Transformer 相比，关系边具有牙弓顺序语义且可解释。

**训练目标与消融。** 可在检测损失后增加 `L_rel`，仅对可确认的相邻关系施加排序、间距和重叠约束，避免把缺牙误判为错误。比较无图模块、固定几何规则、全连接注意力图和牙弓稀疏关系图；报告假阳性抑制率、门牙漏检率、每图多检/少检数以及对局部视野、缺牙和正畸样本的失败率。该方案最适合基于 RT-DETR 的 decoder 后新增精炼层，而不是修改现有训练好的 checkpoint 后直接声称有效。

### 8. 困难混淆物原型对比学习检测头（优先级高）

**模型设计。** 在检测头的分类特征后增加低维表征分支，并维护牙齿、高光、金属固定器/修复体、口唇/设备反光等原型。常规检测损失继续完成牙齿框分类和回归；原型对比损失使真实牙齿候选靠近牙齿原型，使人工确认的困难非牙候选远离牙齿原型并靠近其对应混淆物原型。推理时利用检测置信度和牙齿原型相似度联合评分，作为分类头的一部分参与端到端决策。

**模型创新点。** 将高光和金属部件从笼统背景中分离，针对项目已观察到的外观混淆建立可解释的判别表征。它不要求把所有干扰物升级为正式检测类别，因而仍保持 `tooth` 单类别检测任务；但困难负样本必须经过人工确认，且金属部件的标注边界必须先统一。

**训练目标与消融。** 可采用 `L = L_det + lambda_c L_contrast`，并分别测试无对比头、仅随机背景对比、仅高光原型、加入金属与设备原型的完整模型。应报告困难子集 Precision、每图假阳性数、牙齿 Recall 和嵌入空间的类别可分性；还需对比 focal loss 或 hard-negative mining，证明收益来自原型表征而不是单纯增加困难样本数量。

### 9. 成像质量条件化的多尺度特征调制网络（优先级中）

**模型设计。** 增加轻量质量估计分支，预测过曝高光、反射金属、模糊、遮挡和口腔有效视野等连续质量描述，再以 FiLM 调制或动态卷积调整 FPN 各尺度特征。高光强、金属密集或局部模糊时，网络可降低依赖局部亮度的浅层纹理权重，并增加来自上下文的中高层特征贡献；质量分支以人工标注的图像级或区域级质量标签监督。

**模型创新点与限制。** 该方法使检测器根据干扰类型自适应选择特征，而不是采用对所有图像相同的增强和阈值。它适合解释不同成像条件下性能变化，但需要额外质量标注；若只使用预测置信度作为伪质量标签，无法证明模型真正学到了高光或金属干扰。

**关键验证。** 构建覆盖高光、金属、模糊、遮挡和正常条件的平衡测试子集；比较静态 FPN、仅质量分类辅助任务和完整条件化模块；同时报告各条件下的 mAP、假阳性数、计算量和延迟。该项应排在候选项 6、7、8 之后实施。

## 推荐的论文组织与取舍

建议将候选项 1 定为当前论文的主创新，以现有 before/after 多架构实验为证据。模型创新宜选择候选项 6 作为主方法：它可直接复用现有边界框生成辅助监督，并以候选项 3 的困难样本标注支撑评估；候选项 7 和 8 可分别作为牙弓关系和混淆物判别的两条备选技术路线，避免在一篇论文中同时堆叠多个未充分验证模块。候选项 2 可作为候选项 6 或 7 的无学习后处理对照，候选项 4 用于复核效率提升，候选项 5 仅在完成真实设备评测后写入系统创新。论文中应避免声称 Transformer 天然能消除误检、牙齿必然完整等间距排列，或向量检索本身能提高检测精度；这些均须由上述消融实验支持。

# 可行性落地方案

## 1. 总体取舍与交付目标

本项目宜拆分为两个可独立成立的交付物，而不是一次性实现全部候选项。

1. **数据质量论文主线。** 基于已完成的 OMNI_COCO before/after 成对实验，完成标注规则、修订统计、跨模型复现实验、固定测试集评估和错误分层分析。该部分不依赖新模型，风险最低，可先形成可投稿的研究结果。
2. **模型方法论文主线。** 只选择“牙弓先验引导的双分支检测网络”作为第一版新模型；以原始 RT-DETR-L 或同等规模的单一基线为主体，先验证密度先验，再验证方向先验和特征融合。牙列关系图、原型对比学习和质量条件化模块均保留为后续备选，不应在第一版模型中同时叠加。

最终交付应包括：冻结的数据清单与标注规范、派生监督标签、可复现训练代码、训练配置和权重元数据、验证/测试结果、困难样本错误报告、消融结果以及论文所需图表。所有结论均限定为单类别 `tooth` 边界框检测；不把预测框、牙弓先验或困难样本分数解释为分割、牙位编号或临床诊断。

## 2. 阶段 A：冻结数据、定义标注规则与建立评估集

### 2.1 数据版本与不可变输入

- 保留 `dataset/OMNI_COCO/before` 与 `dataset/OMNI_COCO/after` 作为只读实验输入，使用文件哈希、样本数、标签数和 split 清单记录其版本。
- 训练与模型选择只使用 `train` 和 `val`；`test` 在模型结构、损失权重和置信度阈值确定前不得参与调参。最终测试仅在候选模型冻结后执行。
- 任何由标注框派生的密度图、方向场、困难样本索引或质量标签均写入新的派生目录，并保存生成脚本版本、输入数据版本、参数和哈希；不得回写原始 YOLO 标签。
- 新增外部数据集（包括 AlphaDent 或同类数据）时，先核验许可证、拍摄模态、病例/图像去重、标签语义和类别定义。外部数据不满足“可见牙冠的单实例框”规则时，不能与 OMNI_COCO 直接混合训练或合并指标。

### 2.2 标注决策表与复核流程

先由至少一名口腔专业人员和一名标注执行者形成并冻结决策表，最低应覆盖：完整可见牙、部分遮挡牙、边缘截断牙、牙冠高光、正畸托槽与弓丝、金属修复体、吸唾器、口唇和设备反光。每一项明确“标为牙齿”“不标为牙齿”或“进入待裁决队列”，并给出至少两个图像示例。

复核记录使用独立结构化清单，而不是仅覆盖标签文件。每条记录至少包含图像相对路径、图像哈希、对象框、错误类型、复核前后状态、审核人、审核日期和规则版本。金属部件若在历史标签中存在不一致，不宜在没有规则前直接作为负样本训练；应先完成规则统一和重新审核。

### 2.3 固定困难测试子集

从最终独立 `test` 集一次性抽取并人工确认困难子集，子集的图像不得同时用于训练。建议以图像为单位允许多标签，至少包含：高光、金属/正畸部件、口唇或设备干扰、遮挡、模糊、局部视野、缺牙或牙列不完整、门牙。对每个子集记录真实牙数及干扰物类型；样本不足的子集只报告描述性结果，不将其作为显著性结论依据。

## 3. 阶段 B：建立可复现基线与数据质量证据

### 3.1 基线重跑与实验注册

以已完成的 YOLO11n、YOLO11s、RT-DETR-L、YOLOv8m 和 YOLO26m 结果为历史证据，同时选定一个计算量适中的主基线用于后续模型创新。优先选 RT-DETR-L 作为主基线，因为其 decoder 查询适合接入全局牙弓先验；另保留 YOLO11n 或 YOLO11s 作为轻量泛化基线。

每次正式实验在开始前登记数据版本、训练/验证/测试清单哈希、模型初始化权重及其来源、输入尺寸、batch、epoch、增强、随机种子、硬件和代码提交版本。before/after 对比保持除数据版本外的所有条件一致。建议至少使用 3 个随机种子，并同时报告均值、标准差、单次最佳值和训练失败情况，不能只保留最高结果。

### 3.2 数据质量实验矩阵

| 实验组 | 训练数据 | 模型 | 目的 |
| --- | --- | --- | --- |
| D0 | before | 现有五种基线 | 保留已有成对结果，核验可复现性 |
| D1 | after | 同 D0 | 量化人工复核的跨架构收益 |
| D2 | before/after | 主基线，多个随机种子 | 给出标注质量收益的离散度 |
| D3 | after | 主基线，困难测试子集 | 定位高光、金属、遮挡和边缘样本的剩余问题 |
| D4 | 外部数据仅测试 | 已冻结的 after 模型 | 评估跨数据集泛化，不能据此反调参数 |
| D5 | after 加入外部数据 | 主基线 | 仅在标签语义统一后研究数据规模/域多样性增益 |

外部数据消融应至少比较“仅 OMNI_COCO 训练、外部数据零样本测试、统一标签后混合训练、混合训练后在 OMNI_COCO 固定测试集评估”。这样能够区分数据量增加、成像域变化和标签不一致三种因素；不能将不同测试集上的绝对 mAP 直接横向比较。

### 3.3 基线验收门槛

训练记录完整、训练曲线正常、`val` 指标可复现，且 before/after 的样本清单与评估协议一致，才进入模型创新阶段。数据质量论文的主结论以固定测试集为准；验证集仅用于 checkpoint 选择。所有结果同时报告 Precision、Recall、mAP@0.5、mAP@0.5:0.95、每图假阳性数、每图漏检数、训练成本和推理成本。

## 4. 阶段 C：实现牙弓先验引导的双分支检测网络

### 4.1 最小可行模型

第一版不修改检测类别、不增加分割任务，也不依赖 FDI 标号。输入仍为原始口腔图像，输出仍为 `tooth` 检测框。模型由四部分组成：

1. **检测主干。** 保留 RT-DETR-L 的特征提取、编码器、查询解码和检测损失，确保可与现有基线公平比较。
2. **牙齿密度分支。** 从编码器多尺度特征预测单通道密度图，表示图像各处出现牙齿中心的相对可能性。
3. **牙弓方向分支。** 预测二通道单位方向场，表示牙列在局部区域的切线方向；标签缺失、仅一颗牙或无法确定相邻关系的位置使用有效性掩码，不计算方向损失。
4. **特征融合模块。** 先采用参数量小的门控融合，将密度与方向特征映射为权重后注入编码器输出；门控验证有效后，再将其替换为跨注意力作为增强版本。第一版不得同时加入关系图、原型对比头和质量调制。

### 4.2 从现有边界框生成辅助监督

- 从每个 GT 框计算中心点 `(cx, cy)` 和尺度，以中心点为核、以框宽高或固定比例决定方差，叠加生成归一化牙齿密度图。多个重叠核取最大值或加和后裁剪到 `[0, 1]`，在脚本中固定一种定义。
- 对同图牙齿中心进行稳健排序：先用主成分分析估计牙列主轴，再根据投影排序；若曲率明显，可用低阶样条或局部近邻连接替代直线排序。邻近中心连线的单位向量形成方向场，端点与大间隔区域只监督可确认的局部邻域。
- 为每张图保存派生标签元数据：GT 框哈希、生成器版本、密度核参数、方向有效像素比例及异常原因。生成器必须有单元测试，至少验证空标签、单牙、两牙、重叠框、边缘框和局部裁切图。
- 可视化原图、GT 框、密度图、方向场和有效掩码，人工抽查每个 split；若生成目标与真实牙列形态不一致，应先修正规则或生成器，不应通过调大损失权重掩盖问题。

### 4.3 损失、训练和稳定性控制

总损失从保守配置开始：`L = L_det + lambda_d L_density + lambda_o L_orientation`。其中 `L_det` 完全沿用主基线，`L_density` 可使用带有效掩码的 BCE、Focal 或 MSE，`L_orientation` 仅在方向有效像素上计算余弦损失。`lambda_d` 和 `lambda_o` 只在 `val` 集预先定义的小范围内搜索，并记录所有尝试。

训练顺序如下：先加载与主基线相同的公开预训练权重，冻结或低学习率微调主干，仅训练辅助分支和融合模块，确认梯度、损失和可视化正常；再进行端到端微调。每个设置至少运行多个随机种子。若辅助损失下降而检测 mAP 和困难子集错误均无改善，应终止该分支，而不是继续叠加复杂模块。

### 4.4 代码与产物边界

建议在 `src/toothseg/` 下新增独立研究模块，例如数据派生器、双分支模型、损失函数、评估器和配置定义；CLI 仍只负责解析实验配置和调度。不要直接修改第三方 Ultralytics 或 Transformers 包源码。新模型应在模型目录中使用独立名称和后端标识，checkpoint 写入模型结构版本、配置、预训练来源、数据清单哈希和派生标签生成器版本，以避免把普通 RT-DETR 权重误加载为新模型权重。

在实现前新增针对性测试：派生监督的几何正确性、空标签和异常输入、损失有效掩码、单步前向/反向传播、checkpoint 元数据校验和预测输出格式兼容性。真实 50 epoch 训练不作为单元测试；先执行小样本或 1 epoch 冒烟训练，确认输出目录、权重和验证流程后再启动正式训练。

## 5. 阶段 D：模型实验、消融与统计分析

### 5.1 最小充分消融

| 编号 | 检测主干 | 密度分支 | 方向分支 | 融合方式 | 目的 |
| --- | --- | --- | --- | --- | --- |
| M0 | RT-DETR-L | 否 | 否 | 无 | 公平基线 |
| M1 | RT-DETR-L | 是 | 否 | 无或辅助训练 | 判断密度监督本身的作用 |
| M2 | RT-DETR-L | 是 | 是 | 无或辅助训练 | 判断方向先验的增益 |
| M3 | RT-DETR-L | 是 | 是 | 门控融合 | 最小完整模型 |
| M4 | RT-DETR-L | 是 | 是 | 跨注意力融合 | 仅在 M3 有效时验证融合复杂度 |

所有 M0–M4 使用同一 after 训练集、验证集、输入分辨率、增强策略、预训练初始化、训练预算和种子集合。模型参数量、FLOPs、单图推理时延、峰值显存和训练时间同时记录；若精度增益只来自大幅增加的计算量，需要以等计算量设置或轻量替代模块复核。

### 5.2 错误导向评估

主指标为固定测试集上的 mAP@0.5:0.95；次要指标为 mAP@0.5、Precision 和 Recall。与创新假设直接相关的指标包括：牙弓外假阳性数、高光/金属/设备干扰导致的每图假阳性数、门牙与边缘牙漏检率、每图多检和少检数量。困难子集的人工审核标准、阈值和成员在实验前冻结。

对同一测试图像的模型结果进行配对比较，使用 bootstrap 置信区间或按图像重采样估计指标差异的不确定性。多随机种子结果报告均值和标准差。模型只在 mAP 改善、困难样本假阳性下降且正常牙 Recall 未出现实质性损失时，才可称为有效；若只改善总 mAP 而恶化困难子集，应在论文中如实报告其局限。

### 5.3 失败判定与降级路径

- 若 M1 无收益，优先检查密度目标生成、损失量级和数据标注一致性；确认无误后停止投入方向分支，转向候选项 8 的困难混淆物原型头。
- 若 M2 有收益但 M3 无收益，保留辅助监督版本，将特征融合降为无融合或轻量门控，不为使用跨注意力而增加复杂度。
- 若结构先验减少假阳性但显著降低缺牙、局部视野或遮挡样本 Recall，则仅将其作为“待复核提示”模块，不作为自动抑制模块。
- 若外部数据混合训练降低 OMNI_COCO 固定测试性能，保留外部零样本评估，不把外部数据并入主训练集；后续以域适应或重新标注解决，而不是覆盖现有数据。

## 6. 阶段 E：困难混淆物原型头与关系图的后续实施条件

只有阶段 D 的主模型完成并冻结后，再选择一个后续模块继续。困难混淆物原型头的前置条件是已审核的高光、金属、设备和口唇困难负样本索引；其价值是降低特定类型假阳性。牙列关系图的前置条件是可靠的牙弓坐标与相邻关系生成器；其价值是处理孤立误检和不合理间距。两者不能与首版双分支模型同步立项，否则无法识别性能收益来自何处。

若原型头先行，实验应比较随机背景、hard-negative mining 与原型对比学习；若关系图先行，实验应比较固定规则、全连接注意力和稀疏牙弓图。每次只新增一个独立变量，并复用阶段 D 已冻结的数据、种子和困难测试子集。

## 7. 主动复核、向量检索与部署的实施边界

主动复核系统在模型方法稳定后建设。先从离线错误库开始：保存经过人工确认的漏标、框偏移、高光、金属、设备和遮挡样本的图像块、检测结果、特征向量、哈希和审核状态。检索系统只输出相似样本和审核优先级；复核后的标签必须保留来源与审核记录，不能自动回流为真值。

移动端或云端部署放在研究模型冻结之后。端侧首先验证轻量基线或蒸馏后的模型能否满足指定设备时延、内存和模型大小约束；云端仅在获得合法数据传输与存储方案后处理图像。部署界面应显示检测候选和图像质量提示，避免输出疾病分级或诊断结论。

## 8. 阶段验收清单

| 阶段 | 进入下一阶段的必要证据 |
| --- | --- |
| A：数据与标注 | 数据清单/哈希、冻结标注规则、复核记录、困难测试子集和派生标签抽查通过 |
| B：基线 | 训练配置完整、before/after 对照可复现、固定测试集评估完成、错误分层报告完成 |
| C：实现 | 派生监督测试通过、1 epoch 冒烟训练成功、checkpoint 与预测格式可追溯 |
| D：模型验证 | M0–M3 至少完成，多个随机种子统计完成，困难子集与计算成本均已报告 |
| E：后续模块 | 主模型冻结，困难负样本或关系生成前置条件满足，单模块消融计划登记完成 |
| 转化 | 指定设备性能、数据处理边界和非诊断用途说明齐备 |

该方案的近期重点是完成阶段 A–D。这样既能把已经完成的人工复核实验整理为可靠证据，也能以最少的新标注和最小模型改动验证牙弓先验是否真正降低高光、金属和口外区域造成的检测错误。
