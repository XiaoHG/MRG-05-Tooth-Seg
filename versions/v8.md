# 版本安排
- 源码放在 `src/` 目录下，demo 文件放在 `cli/` 目录下，测试代码放在 `tests/` 目录下
- v8要实现推理的时候指定一个文件夹路径，然后需要迭代该文件夹下面的所有图片文件，包括迭代遍历所有的子文件夹中的文件；
- 并指定推理输出的文件夹；

# 版本分析

- v8 的核心目标是完善批量推理能力：用户传入一个根文件夹后，程序需要递归遍历该文件夹及其所有子文件夹中的图片文件。
- 推理流程应明确限定图片文件的发现、读取和逐张处理逻辑，保证嵌套目录下的图片不会遗漏，同时对非图片文件进行忽略或跳过处理。
- 用户需要能够指定推理结果的输出文件夹，因此实现时应统一管理输出路径，并在批量处理过程中保持清晰、稳定的输入与输出对应关系。
- 工程结构需要遵守目录约定：模型源码位于 `src/`，命令行或演示入口位于 `cli/`，测试代码位于 `tests/`，以便后续开发、运行和验证。
- 本版本的实现重点是推理数据流和工程化组织，不涉及改变牙齿全量分割及氟斑牙分级的任务目标；相关模型推理逻辑应在上述批量文件处理框架中复用。
