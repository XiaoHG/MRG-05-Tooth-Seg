# 月报
一、本月工作与学习：
1. 完善单类别牙齿检测的数据校验、训练、验证与推理整体工程思路；
2. 完成omni_cooc数据集人工复核前后的多模型对比训练、JSON 和可视化输出；包括 YOLO11、YOLOv8、YOLO26、RT-DETR、faster-r-cnn等模型；
3. 完成 Label Studio 预测导入、人工复核与复核后可视化；
4. 结合文献，明确可利用牙弓位置、牙齿相邻顺序抑制高光、金属器械和口唇误检，考虑以 DINOv3 为基准模型进行牙科数据预训练、单牙 token 建模牙间关系及单牙病灶分析氟斑牙分级的研究思路。

二、现存问题：
1. 当前仍是边界框检测，尚未实现分割、FDI 牙位识别和氟斑牙分级；
2. 部分数据标注语义不一致，高光、金属、遮挡及门牙漏检等错误尚未分类统计；
3. 固定测试集、多随机种子和外部泛化证据不足。

三、下一步计划：
1. 冻结标注规则和数据清单，统计复核前后变更，在相同配置、多随机种子下复现实验；
2. 建立高光、金属、遮挡、边缘牙困难子集，报告每图假阳性和漏检；
3. 以 RT-DETR 为主基线，先验证牙齿密度与牙弓方向辅助监督，再决定是否加入注意力融合；
4. 同步核验外部数据标签一致性；
5. 模型稳定后开展 DINOv3 单牙编码器和牙齿实例 token 研究，逐步衔接 FDI 与氟斑牙分级。
