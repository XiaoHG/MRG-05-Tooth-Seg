## 3. 本版本任务与验收标准

### 任务一：多模型对比收尾

- 内容：补齐 before/after 两版本 × 各模型（YOLO11、YOLOv8m、YOLO26m、RT-DETR、Faster R-CNN、RetinaNet、RT-DETRv2-L、RF-DETR-M 等）的完整实验产物。
- 验收：
  - 各模型均产出 `args.yaml`、`results.csv`、`weights/best.pt`、验证图、日志。
  - 指标统一记录（P/R/mAP50/mAP50-95 + 训练耗时 + 推理速度），使用固定 val 集。
  - before/after 各自内部排名 + 同模型跨版本差异分析，不把标注差异误判为模型能力。

### 任务二：冻结数据与评估协议

- 内容：冻结标注规则与数据清单，固定 test split，划分困难子集（高光/金属/遮挡/门牙）。
- 验收：
  - 数据清单 + 标注规则冻结（文档 + 哈希）。
  - 固定 test split（不参与调参）。
  - 困难子集划分脚本 + 样本量统计。

### 任务三：下游检测基线复现

- 内容：在固定协议下复现 YOLO11 与至少 1 个 DETR 基线（如 DN-DETR / DINOv3），作为论文 A 的下游 baseline。
- 验收：
  - 复现 YOLO11 与 ≥1 个 DETR 基线，指标可复现。
  - 困难子集每图 FP/FN 统计表 + 误检类型占比。
  - 错误案例可视化（支撑论文 A 的「结构先验 / 域内预训练」动机）。
