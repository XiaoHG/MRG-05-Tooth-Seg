# 版本分析

## 1. 本版本定位

- A1（v14）已产出多源数据集清单与噪声剔除规则；本版本承接其数据，落地「OralDINO 预训练」的运行环境与脚本。
- 自监督预训练只看图像、不看标签，因此第一步是跨数据源 SHA256 去重，避免 `OMNI_COCO` before/after 同图两版、合并集重叠导致重复训练。
- 预训练权重门控（HuggingFace），需 `HF_TOKEN`；Blackwell `sm_120` 依赖 PyTorch ≥ 2.7.1（cu130/cu128），`lab_train/setup_env.sh` 已保证。

## 3. 本版本任务与验收标准

- 内容：在 `lab_train/` 内配置预训练环境与脚本，准备去重后的预训练数据清单。
- 验收：

  - 预训练权重 + 线性评估（后者实际在 v16 完成，本版本只搭好断点与输出结构）。

## 4. 本版本执行结果（收口记录）

- **数据准备**：新增 `lab_train/pretrain/prepare_pretrain_data.py`，跨目录递归扫描图像、按 SHA256 去重、写 `dataset/pretrain/pretrain_manifest.json`（`unique`/`seen`/逐图相对路径 + 哈希）。`dataset/` 采用「一数据集一目录」布局（除 `pretrain/` 外按公开数据集命名，直接放口内图像），脚本默认自动发现这些目录；`pretrain.py` 对空清单加守卫。
- **预训练脚本**：新增 `lab_train/pretrain/pretrain.py`，精简 DINO 参考实现——`DINOHead`（3 层 MLP + weight-norm）、2 全局 + N 局部多裁剪、DINO 交叉熵损失（teacher 中心化 + 温度锐化）、AdamW + 余弦 LR + 余弦 EMA 动量、AMP、定期断点 + 最终 `teacher_checkpoint.pt`。
- **依赖与文档**：`lab_train/pyproject.toml` 新增 `pretrain` extra（`transformers>=4.49`、`torch>=2.7.1`、`torchvision>=0.20`）；`setup_env.sh` 新增 `--pretrain`；`lab_train/README.md` 新增「七、DINOv3 域内预训练」章节。
- **测试**：`tests/test_pretrain_data.py` 覆盖 SHA256 去重、相对路径、非图像过滤。
- 说明：真实预训练权重产出留待服务器执行；下游线性评估/有效性验证（A3）在 v16。`kaggle_train/colab_train` 不做预训练适配（预训练固定在 lab_train 的 96 GB 卡）。
