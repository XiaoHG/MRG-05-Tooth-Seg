# 版本安排
- 源码放在 `src/` 目录下，demo 文件放在 `cli/` 目录下，测试代码放在 `tests/` 目录下
- v7增加训练时候加载best.pt进行继续训练的方式，因为我会一直增加数据，知道模型权重能够符合我指标要求；

## 版本分析

### 1. 版本定位

v7 是在 v6 伪标签数据整理基础上的增量训练版本。由于后续会持续增加经过审核的数据，训练流程需要支持从已有模型权重初始化新一轮训练，而不是每次都从 `yolo11n.pt` 重新开始。本版本的主要目标是加载上一轮表现最好的 `best.pt`，使用新增训练数据进行微调，并在固定的人工标注验证集上重新评估模型效果。

本版本仍然是单类 `tooth` 检测任务，不涉及 FDI 牙位识别、氟斑牙分级或像素级分割。v6 产生的伪标签只能进入训练集，不能进入验证集。

### 2. 当前训练行为

当前 `src/toothseg/model.py` 中的训练逻辑固定使用：

```python
model = YOLO("yolo11n.pt")
```

因此，即使已经存在上一轮的 `best.pt`，直接执行当前 `train` 命令也不会加载该文件，而是从基础预训练权重重新启动一轮训练。当前 CLI 也没有 `--weights` 或 `--resume` 参数，`best.pt` 目前只被 `val` 和 `predict` 命令使用。

### 3. 权重选择策略

需要区分“新增数据后的微调”和“中断训练后的恢复”两种情况：

- 上一轮训练已经完成，增加 v6 审核通过的数据后，推荐加载上一轮验证集表现最好的 `best.pt` 作为新一轮训练的初始化权重。该方式使用效果最好的模型参数适应新增数据，适合持续扩充数据集的迭代流程。
- 上一轮训练因程序中断、机器故障或时间限制没有完成，推荐使用 `last.pt` 并开启断点续训。该方式用于恢复最近一次训练状态，通常还会恢复优化器、学习率调度器和 epoch 进度。
- 如果需要建立完全独立的基线，才从 `yolo11n.pt` 重新训练。重新训练结果应使用新的实验名称保存，不能覆盖已有 v5 或 v6 权重。

因此，本版本的主要策略是：

```text
上一轮 best.pt + 新增且审核通过的数据
    -> 新实验目录中的 v7 微调
    -> 固定人工标注验证集评估
```

加载 `best.pt` 进行新一轮训练不等同于完整断点续训。它主要复用模型参数，不应默认沿用上一轮的训练进度；学习率、训练轮数和实验目录应作为新一轮实验重新配置。

### 4. 代码改造要求

训练接口应增加可选的初始化权重参数，例如 `weights`，默认值保持为 `yolo11n.pt`，以兼容从头训练：

```text
train --weights output/train/<previous-experiment>/weights/best.pt
```

同时应提供明确的断点续训选项，例如 `--resume`，只有在用户明确要求恢复未完成训练时才启用。`--weights` 和 `--resume` 的语义必须区分，避免把 `best.pt` 当作断点文件恢复优化器状态，也避免把 `last.pt` 的中断状态误用于新的数据迭代。

训练输出应保存到新的实验名称下，例如 `tooth-detect-v7`，并记录：初始化权重路径、数据集 manifest、训练参数、验证指标、生成时间和最终的 `best.pt`、`last.pt`。训练前应确认数据集已通过校验，且固定验证集未被伪标签重新划分。

### 5. 推荐训练流程

1. 审核 v6 候选伪标签，只将审核通过的完整图像和标签发布到 `dataset/raw/pseudo-label-v6/`。
2. 使用固定验证集 manifest 重建 `dataset/images/train`、`dataset/images/val`、`dataset/labels/train` 和 `dataset/labels/val`，确保伪标签只进入 train。
3. 校验图像与标签一一对应，并确认原有人工标注验证集的文件清单没有变化。
4. 以 v6 或上一轮已接受版本的 `best.pt` 作为初始化权重，启动新的 v7 实验；不直接覆盖旧实验目录。
5. 在同一份人工标注验证集上比较新增数据前后的 precision、recall、mAP50 和 mAP50-95，并检查漏检、误检和异常框案例。
6. 只有当验证集指标和错误案例满足目标时，才将本轮 `best.pt` 作为下一轮数据迭代的初始化权重。

### 6. 风险与验收标准

持续加载上一轮 `best.pt` 可能放大模型已有的偏差，尤其是伪标签由同一模型生成时，容易产生确认偏差。因此每轮新增数据都必须经过人工审核，并使用固定人工真值验证集判断是否接受新权重，不能只依据训练集损失或伪标签数量判断效果。

本版本验收要求如下：

- 训练命令能够显式指定 `best.pt` 初始化训练；
- 需要恢复中断任务时能够显式使用 `last.pt` 断点续训；
- 默认从 `yolo11n.pt` 开始的行为仍然可用；
- 新增伪标签不会进入固定验证集；
- 每轮训练均保存独立的权重、参数、数据 manifest 和验证结果；
- 新模型在固定人工标注验证集上的指标不低于接受标准，或能够明确记录下降原因；
- 若指标下降，可根据 manifest 回滚到上一轮 `best.pt` 和对应数据集，而不是继续叠加未经验证的新增数据。
