

## 一、前置部分（正文前）
1. **标题 Title**：简洁，点明研究对象、任务、方法，突出创新点
2. **作者与单位**：作者姓名、单位、基金项目、通讯作者邮箱
3. **摘要 Abstract**：研究背景+问题+方法+实验结果+结论；独立可读，不引用文献
4. **关键词 Keywords**：3~8个，覆盖领域、数据集、模型、任务

## 二、正文主体（核心章节）
1. **引言 Introduction**
    研究背景 → 现有痛点 → 现有方法不足 → 本文研究目标 → 核心创新点（1~3点）→ 论文组织结构。
2. **相关工作 Related Work**
    领域研究脉络梳理，分类归纳现有方法；对比分析现有方法局限；**不要单纯罗列文献**，突出和本文的差异。
3. **方法 Methodology**
    任务定义、数据集说明、网络/算法架构、损失函数、训练策略、模块设计；公式、结构图，描述可复现。
4. **实验 Experiments**
    - 实验设置：数据集、评价指标、基线模型、软硬件环境、训练超参
    - 对比实验：与SOTA方法定量+定性结果对比（表格、可视化图）
    - 消融实验：验证每个创新模块有效性
    - 分析实验：参数敏感性、案例可视化、失败样例分析
5. **讨论 Discussion（部分期刊/学位论文单独放，会议论文常合并到实验）**
    解释实验现象，分析为什么本方法有效；客观分析优势；讨论局限性。
6. **结论 Conclusion**
    简要复述工作；总结核心发现；研究局限；未来工作展望。
